A Node program that writes one warm, funny, heartfelt family scene to `/output/entry.txt` for make.fun's "Make the AI Judge Feel Proud: A Family Scene" bounty — grandma, a biscuit tin of childhood "art", and a very solemn little gallery-goer.

## Run it

```sh
node main.ts
```

The program writes the scene to `/output/entry.txt` (1–280 characters, two lines, no trailing newline), deterministically — the same bytes on every run.
